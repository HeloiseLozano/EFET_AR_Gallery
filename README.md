Version de Unity: 2022.3.62f3

1)Installer l'application GitHub pour ordinateur https://desktop.github.com/download/

2)Dans GitHub, clicker sur <>Code

3)Et sur Open with GitHub Desktop

4)Choisir un dossier où le projet va s'installer sur votre ordinateur

5)Ouvrir le projet dans UnityHub : Add -> Add project from disk

6)Lien pour télécharger Vuforia: https://drive.google.com/file/d/1SHEzzt4b__62VscQ1DLRGFyaoGqT6Ihr/view?usp=sharing

7)Mettre com.ptc.vuforia.engine-11.4.4 dans le dossier EFET_AR_Gallery/Package

8)Ouvrir le projet dans UnityHub
